Fix an empty local database

From the folder containing app.py, run this in PowerShell:

python sync_data.py

If the original PTM-SiteDB source server is unreachable, import a real tab-separated export instead:

python import_tsv.py .\ptm_sitedb.tsv

The export needs the columns gene, uniprot, ptm_type, and site. Never copy example or synthetic records into the database.

Help

How to use the enhanced PTM-SiteDB.

3D structure mapping

The viewer uses an experimental PDB structure when a valid structure is found for the selected UniProt protein. If an experimental structure is unavailable, it can fall back to AlphaFold. A PTM is highlighted only when residue mapping is verified; otherwise the site is explicitly shown as unmapped.

Evidence and confidence

Evidence and confidence shown in the tables come from the imported PTM-SiteDB records. The application does not invent missing values.

Analysis Suite

Nine separate modules (menu: Analysis Suite). Each one states its method and assumptions, and reports \"not available\" instead of guessing when an external source cannot answer.

Data synchronization

Run python sync_data.py to retrieve the displayed records from the original PTM-SiteDB search pages into the local SQLite database, or python import_tsv.py export.tsv to import a TSV you exported from the original site.

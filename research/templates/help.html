From raw sources to a valid analysis

The app runs locally, and its primary analysis requires real, assembly-matched genomic and structural inputs.

1. Download real sources

Run INSTALL_AND_RUN.ps1 or python scripts/bootstrap_sources.py. The official dbPTM phosphorylation source and an IntOGen driver archive are needed. If IntOGen is blocked, place the official archive in data/raw/IntOGen-Drivers-20240920.zip and rerun the bootstrap. The release declared inside the archive is recorded; filenames are not treated as proof of release.

2. Build the panel

Run python scripts/build_200gene_panel.py. The balanced target is 100 IntOGen-listed PTM-bearing drivers and 100 PTM-bearing genes not listed in that release. Every selected row comes from source tables; if a group lacks enough genes, the panel reports its actual size.

3. Prepare genomic opportunities

Download a genome FASTA and GTF/GTF.GZ from the same assembly (GRCh38 recommended). Run PREPARE_GENOMIC_INPUTS.ps1 with both full file paths. It enumerates missense SNV opportunities and fetches/matches AlphaFold CA coordinates. This can take a long time for 200+ proteins.

4. Run a real MAF

Use Run Analysis to upload a somatic MAF from the same genome assembly. The MAF must have gene, chromosome, start position, reference allele and alternate allele columns; non-SNVs and non-missense consequences are excluded. The FASTA must match the assembly and has a .fai index.

QC and limitations

  • Untestable/partial gene statuses are not counted as negative results.
  • The null preserves observed SBS96 context counts within each gene and samples from possible coding missense opportunities. It is not fitted COSMIC signature deconvolution and does not control for all regional mutation-rate or callable-region effects.
  • AlphaFold coordinates are predictions, not experimental structures; mapping identity/coverage are recorded.
  • “Not listed in IntOGen” is not a confirmed biological non-driver label.
  • Independent cohort status and sample overlap must be assessed by the researcher; this website does not automatically verify patient overlap.
  • TP53 S127 is shown only when present in real results and must remain hypothesis-generating unless independently supported.

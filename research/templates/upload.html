Inputs and alignment rule

Use GRCh38 MAF + GRCh38 FASTA + GRCh38 GTF together (or a consistently matched GRCh37 trio). The opportunity map chooses MANE Select, then Ensembl canonical, then longest-CDS fallback. MAF rows are mapped by genomic coordinates to the same selected transcript; incompatible events are flagged.

3D coordinate rule

The coordinate table must use the same canonical protein residue numbering as the opportunity map. The included AlphaFold fetcher aligns sequences and keeps only identical-residue mappings. Predicted coordinates are not experimental structures; source and mapping QC are retained.

First-time genomic preparation

Open PowerShell in the website folder and run:

.\PREPARE_GENOMIC_INPUTS.ps1 -ReferenceFasta "C:\data\GRCh38.fa" -Gtf "C:\data\gencode.annotation.gtf.gz"

Use a fasta with a .fai index or let the script create one. Do not mix assemblies. For long downloads, run the script directly rather than through the browser.

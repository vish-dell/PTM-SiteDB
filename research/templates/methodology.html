PRE-SPECIFIED PROTOCOL

One primary benchmark. Secondary robustness stays secondary.

The protocol is declared before cohort analysis; the 12 threshold settings per cohort (24 across the prior BRCA/LUAD-style two-cohort sweep) are not searched for a post-hoc “best” result.

Primary hypothesis

H1: Among genes with experimentally recorded PTM sites and sufficient primary QC, the distribution of gene-level −log10(SBS96-null p-values) is shifted higher for IntOGen-listed cancer driver genes than for PTM-bearing genes not listed in the selected IntOGen release, using the same reference build and selected-transcript rule.

Unit of primary analysis: gene-level calibrated p-value. Primary settings: sequence separation ≥8 amino acids; CA–CA distance ≤10 Å; 5,000 permutations; random seed 1. The pre-specified group-level test is one-sided Mann–Whitney U on each eligible gene’s -log10(p) score. Per-gene BH q-values and the Fisher exact comparison of q<0.05 hit fractions are complementary gene-level summaries.

v1.1 amendments (11 Oct 2026, before any expanded-panel run)

  1. Recurrence: each mutated residue counts once; legacy per-variant counting is reported as a sensitivity column.
  2. Decoy anchors: real PTM anchors are compared with 1,000 same-gene sets of non-PTM residues matched on amino-acid identity and anchor count (decoy z, p, q).
  3. Primary endpoint: one-sided stratified permutation test of the decoy-calibrated score, driver vs not-listed, with labels permuted only within mutation-burden × PTM-anchor strata. The v1.0 Mann–Whitney test above is retained as secondary.
  4. Grid correction: the 12 threshold settings are Benjamini–Hochberg corrected as one family per cohort.

Unchanged limits: CA–CA distance, AlphaFold predictions, one transcript per gene, no regional mutation-rate model, "not listed" is not a validated non-driver label. See PRE_SPECIFIED_ANALYSIS_PLAN.md.

Historical six-gene baseline (separate from this expanded analysis)

Primary finding: the earlier six-gene analysis did not show significant protein-level PTM-proximal 3D enrichment in TP53, EGFR, AKT1 or CTNNB1 under its pre-specified primary setting. BRAF and BRCA1 were untestable because structural eligibility/QC failed, so they were not biological negatives. The TP53 S127 site-level sensitivity pattern is hypothesis-generating only and did not independently replicate at the protein level. These historical findings are not presented as results of the new expanded panel.

Data and transcript mapping

  1. Import experimental PTM sites from the public dbPTM source.
  2. Import the official IntOGen driver catalog and preserve the release/source metadata.
  3. Choose MANE Select, then Ensembl canonical, then longest coding transcript as a disclosed fallback.
  4. Enumerate all possible missense single-nucleotide opportunities in those coding transcripts using the matching FASTA/GTF.
  5. Map PTM and cancer-mutation positions only where sequence mapping supports the residue coordinates.

96-context opportunity null

  1. Compute SBS96 context independently for each observed MAF SNV using the reference FASTA.
  2. Match MAF variants to the selected transcript using gene + chromosome + position + ref + alt.
  3. Within each gene, sample from possible coding missense opportunities with the same observed SBS96 context counts.
  4. Count events within sequence separation ≥8 and CA distance ≤10 Å.
  5. Use the add-one Monte Carlo p-value and BH q-value across eligible primary genes.

This is a gene-specific spectrum-matched empirical null; it is not a fitted COSMIC signature mixture and does not model regional callable coverage, replication timing or all context-dependent selection.

QC / testability rules

Untestable ≠ negative. Missing CA coordinates, non-mapping transcript annotations, mismatched reference contexts, or missing gene-specific context opportunities are explicit QC statuses and are excluded from the primary test family. Partially mapped genes are shown, but are not counted as primary hits.

Genes not listed in IntOGen are labelled “not listed in this release”, not biological negatives. PTM sources are mapped to a selected accession/protein sequence before structural testing; unmapped sites are not silently projected.

Secondary analyses

  • Threshold matrix: sequence separation 8/12/20 residues × CA distance 6/8/10/12 Å, fully shown for every cohort with no-hit cells retained.
  • Site-level PTM-anchor analysis with across-site multiple-testing correction.
  • Independent same-cancer cohort analysis, with no claim of replication if q-values do not pass the same pre-specified protein-level criterion.
  • TP53 S127 is only reported if it exists in the actual mapped PTM data/results; it stays hypothesis-generating and did not replicate in the previous independent cohorts.

# Data directory

No fabricated biological records are bundled here.

Expected files after setup:

- `raw/dbptm_phosphorylation.zip`
- `raw/IntOGen-Drivers-20240920.zip`
- `processed/ptm_sites.tsv`
- `processed/intogen_drivers.tsv`
- `processed/benchmark_panel.csv`
- optional cohort MAFs and reference FASTAs under `raw/` or user-selected paths

The source manifest records the bootstrap UTC time, archive-declared IntOGen release where available, source URLs, relative paths and SHA-256 hashes so analyses remain auditable. The filename date is not treated as the scientific release.
